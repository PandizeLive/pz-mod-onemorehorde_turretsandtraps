# 0.2.71.12 multiplayer test build

C557 packages the C555 prototype selected in C556 option 1A. When a nonlethal hit settles, the server can immediately send the next waiting hit for that zombie if it is first in line and the queue still has time. The first hit on an idle zombie still leaves immediately. Rotary Bat, Rotary Blades and other defenses use the same queue.

The two promoted combat files match the tested prototype by SHA-256. This release changes no save format, Sandbox option, client protocol or Martyrdom timing. [Verification and connected test](TEST_v0.2.71.12.md)
