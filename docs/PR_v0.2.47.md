# Module Packs, loot weights and battery hours

Adds loot-only Module Packs with three independently weighted rewards, a skippable optional reveal and a configurable 15% zombie-body drop chance. Applies the owner's 29 exported defaults without overwriting saved tuning. Battery estimates switch to hours at 60 minutes; module inventory descriptions bypass the native percent-formatting error.

The new corpse route runs only on death and guards repeat rolls. Rewards are committed before presentation; failed grants retain the same draw. Native transactions/persistence, Kahlua regressions, package isolation and LootLab checks are recorded in [TEST_v0.2.47.md](TEST_v0.2.47.md). Rendered gameplay remains pending; capacity warnings remain open. No multiplayer enablement or Workshop release.
