# Controller-powered triggers and Laser Sensor

Adds a persistent wall Lever and a single-unit Laser Sensor with adjustable 1-10-tile coverage. All four trigger types now use their assigned Controller's supply, retain links through outages and show exact consumption with shared OMH ratings. Detection-equipped rotary turrets wait for a detected target.

Authority, fractional battery costs, native construction, obstacle handling and restart persistence are covered by the 0.2.60 validation suite. See [verification](TEST_v0.2.60.md) for evidence and pending rendered/connected-player acceptance.
