# 0.2.27 — range controls and turret reliability

Turrets previously treated fences as solid firing obstacles and inherited severe long-range sight penalties. This update separates firing visibility from movement collision, adds an engagement slider and configurable 60/80 accuracy defaults, and previews actual zombie hearing distance through a local option.

Rotating shared work budgets and active-time cycle persistence reduce clustered processing and prevent offline/pause reload progress. Isolated Firearms B42 checks exercise 51 conventional guns with 153 conserved shots. See PATCH_v0.2.27.md and RELEASE.md for verification and limits. Rendered client performance and full-modpack acceptance remain owner tests; MP is not enabled.
