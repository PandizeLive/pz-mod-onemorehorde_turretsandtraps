# 0.2.54.1 — Controller input assignment and Siphon rarity

- Automatic Controller assignment
- Remote input management feedback
- Legendary Siphon / LootLab catalog

New Buttons and Pressure Plates join the nearest writable Controller with a free input slot within 20 tiles on the same floor. Configure receiver links from the powered Controller; existing inputs remain assignable there. No need to stand beside each input. Existing permissions, limits and explicit receiver selection remain.

Siphon loads at weight 3, matching the default Legendary tier. The hosted catalog now includes it and preserves saved weights/tiers. [Tests](TEST_v0.2.54.1.md) · [Contract](CORRECTIONS_C310.md#c315--siphon-rarity-and-automatic-input-assignment-2026-10-18).
