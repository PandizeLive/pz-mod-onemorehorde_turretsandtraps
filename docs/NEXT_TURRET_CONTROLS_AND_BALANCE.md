# Turret controls, combat and loot checkpoint

The owner lifted the 2026-10-01 gameplay hold on 2026-10-02 and approved combining the patch with the LootLab update. See [v0.2.23](PATCH_v0.2.23.md) for the implemented scope, verification and combined test. The earlier map-only release used installed 0.2.22; this release uses the shared 0.2.23 definitions.

Native critical chances **and native critical damage** are the approved policy. New-world estimates and probability ranges remain the LootLab policy. The three additional loot pools use component-specific subsets; the original four pools retain all components. Module crafting, additional firearm adapters, multiplayer authority and the remaining trap roster are separate checkpoints.
