# 0.2.49 - New turret heads

- Ballista Head
- Rotary Bat Head
- Rotary Blades Head
- Integrated head-mount recipes
- Rotary motor battery display
- Module compatibility feedback
- Module Pack timing polish

Three craftable heads reuse the universal base. Ballista consumes crafted spears; rotary heads have two physical arms and optional360 spin. Only the base needs maintenance. Recipes include the agreed integrated mechanism and eight Ballista nails. Existing final-art restrictions apply: cube markers are technical prototypes, with owner rendered acceptance still pending.
