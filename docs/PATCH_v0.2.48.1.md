# 0.2.48.1 - Staggered pack reels

- Staggered top-to-bottom rolls
- Longer reel animation
- Faster opening spin
- Individual reward reveals

Rows start 350 ms apart and spin for six seconds each, stopping at 6/6.35/6.7 seconds. Initial speed is twice the old roll. Each row expands/pulses when it lands; the existing selection and single highest-rarity cue wait for the bottom row. Collect still works immediately. Reward odds and loot settings are unchanged.
