This means T&T's client actor lookup lacks those IDs; it does not alone establish whether native networking never created them, the client index missed them, or they were removed/recycled. Nine further requests are rejected while paused. Repeated server targeting of unavailable client actors is a material clue to the wrong-target report, not proof of its sole cause.
- C534 added a250ms age rejection for Ray presentation. A production receiver replay sends six distinct, first-arrival Splitter rays: all six accepted at0/100/200/249ms; all six dropped at250/350ms. Existing tests verified stale suppression and immediate receipt but failed to establish an acceptable first-arrival latency envelope. That verification gap is ours.
