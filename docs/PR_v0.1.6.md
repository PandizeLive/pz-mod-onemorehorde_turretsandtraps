# v0.1.6: directional 1x2 Spike Barrier

Spike Barriers previously retaliated against attackers on every face and occupied one tile. They now occupy two tiles across their width, share durability/removal/rotation, and retaliate for 20 damage only from the front and side ends. Rear strikes are consumed without damage. Existing barriers expand only into clear space and keep their identity and condition.

Adopts Horde Night's numeric versioning, exact public project name, stable OMH.cmd menu, local release tags and cumulative changelog process. Existing internal IDs and historical build evidence remain intact. GitHub/Workshop actions are explicitly unavailable until this project's remote/item are configured.

Validation: native Kahlua/translation/animation/save-table/packet checks, barrier lifecycle fixtures and isolated server startup/save/shutdown. Player validation of live two-tile collision, rotation, safe rear and cleanup is pending. Multiplayer combat remains disabled. This is local release documentation; no PR or Workshop upload has been created.
