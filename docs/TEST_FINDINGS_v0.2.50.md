## Decisions proposed, not selected

**1: Scrapshot balance.** Recommend **1A:** eight20-damage pellets (160total),60-degree pellet spread, retain90-degree target-acquisition FOV,8-tile range and existing cadence. This improves concentration and damage without increasing ray count. **1B:** eight25-damage pellets (200total), retain90-degree spread for a wider crowd weapon. **1C:** retain eight15-damage pellets (120total), tighten spread to60degrees only. Any choice still needs actual close/far and crowded-target comparison; aim scatter and no-center-ray geometry remain relevant.

**2: Detection and signal operation.** Owner selects C2581A: triggers switch receiver operation; receivers retain battery/generator/grid consumption. Existing TurretModules.detects requires MotionDetection and master power; TurretAutomation acquires/aims with it and only fires automatically with Firing. Without Firing it explicitly reports tracking-only. Manual Fire is a separate path. Removing Detection therefore stops automatic aiming/acquisition, but is not equivalent to an ON/OFF signal or physical rotation lock.

Recommend **2A:** preserve ordinary unlinked automation; explicitly linked receivers wait for signals, retain Detection for target acquisition and Firing for autonomous actuation, and omit the redundant proposed Allow turning toggle. Mechanical receivers keep their own signal response. **2B:** all turrets require a signal connection, deliberately replacing standalone autonomous activation. Do not infer2A/2B approval from the owner's question. Remaining no-Detection directional-shot behavior must not be silently invented; reuse verified existing manual behavior only where its contract applies.

The requested UI,10-second Lure loop and tooltips are recorded direction. Scrapshot tuning and signal scope remain choices. No new recipe, module or art requested. Recommend High reasoning for implementation; this multi-system correction is likely over25minutes, so Fast is appropriate if available.
