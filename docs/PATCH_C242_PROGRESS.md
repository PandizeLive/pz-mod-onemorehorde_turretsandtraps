# C242 multiplayer inventory and Manage — unfinished combined patch

2026-10-14. Owner explicitly requests continuing the remaining multiplayer implementation without waiting for their test. C235/C240/C241 authorization continues; no balance changes or new approval gate. Installed 0.2.49 is unchanged.

## Implemented

- The existing Manage panel now opens on MP clients. Shared reach checks replace client imports of server world logic. Client refresh reads inventory/status without advancing reload timers or changing feed counts. The current development panel keeps Fire/Power disabled and omits the unfinished world range overlay.
- Globally registered server-completed transfer actions carry the exact turret identity, native item, direction and optional carried destination bag. They validate reach, source ownership, favorites, supported components, exclusivity, slot/ammo limits and physical capacity again at completion. A failed native insertion restores the original source before sending inventory updates. Duplicate completion and stale/wrong item identities cannot grant duplicates.
- Manage and ordinary native inventory drags involving a placed turret use the same action. Light ammunition merges into at most twenty same-type exact item IDs before native action serialization. The server bounds and validates the batch and checks capacity after each committed item; a partially full turret accepts only the portion that fits. Transaction-local counts avoid rescanning the entire reserve for every round. Native transfer follow-up callbacks and attachment/hand/worn-equipment cleanup are retained.
- Magazine servicing is now a shared/global native timed action with explicit turret and mounted-gun identities. Server completion does not depend on client `start()` fields. Native gun fields and item modData are synchronized; insertion/ejection conserve magazine rounds and the chamber. Failed/no-room ejection preserves the loaded gun. SP startup/interruption behavior remains.
- Range and Filter priority changes are server-completed, whitelisted control actions. Range values must be finite, integral and within the current configuration. Slider changes coalesce until release; there is no per-tick network polling. Unknown controls cannot enable unfinished firing.
