How the estimates work · sources and limits

Geometry and room/container positions come from your installed Knox Country map, not a hand-drawn approximation. Native Lua exports provide procedural pool routes and sprite container properties. Component weights and eligible pools come from T&T 0.2.26. Electronics pools offer every component. Ordinary shelves have lower weights; electronics crates and military electronics retain stronger jackpot chances. Garages, tool stores, electrician tools, gun-store accessories and mechanic cabinets offer themed subsets.

For each item and each roll: p = clamp(ceil(weight × pool scale × global × item multiplier × MaterialLootNew × 100) / 10000). A zero item/global multiplier removes the entry. The native roll count is at least one: max(1, floor(pool rolls × RollsMultiplier)). Loot weights are independent roll chances, not shares of a fixed prize pool; raising one component does not automatically lower another.

Refresh chooses a new map seed and generates one synthetic world: choose each container’s pool with shared room quotas, then roll each component using that pool’s item chance. Components use independent seeded streams; hiding one never rerolls it or the others. Counts shown beside each component are generated items, including multiple copies in one container. Container chances uses matching colors and opacity for probability.

256 seeded scenarios shuffle candidate-container order within each room, apply matching forced tiles and approximate weighted pool selection with room quotas. Item counts use binomial draws. The displayed central 90% interval describes this model's randomness, not its accuracy against the real world.

Limits: native Java map iteration and player exploration order may differ. Quotas consumed by non-candidate containers in the same room are not simulated. Container capacity, nested inventories, room stories, replacements, vehicles, corpses, respawn, mod maps and other mods are not simulated. Multi-sprite objects are candidates until runtime confirms their containers. Retention applies independent losses; real capacity losses can be correlated. These effects can move results outside the model range.

All floors are included. Full-county totals mean eventually generating all mapped candidate containers, not the loot already available around a new character. Town totals use the closest native town label. This is a personal tuning tool; it does not edit or upload the mod.
