# Project tools

Phase 1 prototype tooling is implemented; no publisher exists. Current validation output is `diagnostics/v<packaged-version>`; earlier checkpoint evidence is retained separately. Native animation parsing now verifies the barrier's two strike markers and matching variable bindings.

- [build_cube_placeholder.py](build_cube_placeholder.py): cube-only GLB/glTF and offline previews.
- [build_foundation_sprite.py](build_foundation_sprite.py): the legacy cube plus sixteen potato facings, four barrier arrows and one foundation marker; white technical footprints/labels only; no art direction or native 3D rotation claim.
- [validate_foundation.py](validate_foundation.py) and [KahluaCheck.java](KahluaCheck.java): native JSON translation loading/formatting, installed Kahlua compilation, native table/packet serialization, behavioral doubles, translation/asset checks and SHA-256 package manifest.
- [Install-Foundation.ps1](Install-Foundation.ps1), also available through the [project launcher](../OMH.cmd): verified local copy; refuses an unmanaged existing installation and backs up an earlier managed copy. It does not enable mods, alter saves or publish.
- [smoke_server.py](smoke_server.py): repeat the prepared isolated localhost server restart, then quit cleanly. Requires the existing `diagnostics/p1c1/server-cache` test configuration/database from the recorded first start. It is a developer check, not the connected-player acceptance test.

The placeholder generator requires Python, NumPy and Pillow, available in the bundled workspace Python runtime used for this task. It produces unstyled technical geometry without an image-generation model. Read the [asset notes](../art/placeholders/cube_turret/README.md) for limits and rebuilding.

## Independent package workflow (0.2.29 onward)

0.2.30 appends 24 Bed Spikes tile identities to Traps (52 total), with distinct build/deploy identities and eight white technical marker pages generated by build_bed_spikes.py. Native bed fixtures cover three recipes/four facings plus fresh-process part/global-authority persistence. NativeAudioTiming.java is an isolated muted FMOD operation probe; it cannot certify dense-world client smoothness. record_local_release.py verifies source/tag/install/archive/backup bytes and reads test counts from current version evidence.

Edit canonical `Source/`, then run `build_packages.py`. Both generated entries under Contents are committed and installed; Source is not a selectable mod. Shared helpers/translations are generated identically, with one native load per virtual path. `build_packages.py --check` rejects drift; `verify_packages.py` checks closed requires, component isolation and distinct settings. `smoke_packages.py` runs actual Traps-only, Turrets-only and reverse-order combined startup. Native write/read uses a version-local cache prepared by smoke_server.py.

The former combined registry is a canonical build input only: generated Traps owns registry 7316 / omhtt_barrier_01 (72 tiles); Turrets owns 7317 / omhtt_turret_01 (21 tiles). Fresh worlds are required for this split. Install-Packages.ps1 replaces the old implementation; Install-Foundation.ps1 is only a compatible wrapper. test_release_tools.py invokes the package fixture suite, including rollback under injected failure. Local LootLab package metadata is checked by loot_site/test_package_defaults.py without changing hosted data.

## Native pitch maintenance (0.2.38.1)

Run `build_sound_pitch.py` after editing the two owned sound script files. It expands each distinct clip to the original 101 equally weighted pitch values (0.950-1.050), preserving other fields and sample weighting; running it again is idempotent. Do not add an emitter `setPitch` call to playback. `validate_foundation.py` checks the generated definitions and runs `NativePitchCheck` against the installed sound parser and native emitter, verifying random selection and queued FileSound pitch with existing files. This is not a rendered stress or listening test. Native event sounds and third-party definitions remain untouched.
